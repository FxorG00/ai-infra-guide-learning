# 内存带宽

内存带宽可以先理解成：

> **内存每秒能给计算单元“送多少数据”。**

单位通常是：

```text
GB/s
TB/s
```

比如：

```text
DDR5 ≈ 100 GB/s
```

意思是：

> 每秒大约能搬 100 GB 数据。

而：

```text
HBM3 ≈ 3 TB/s
```

就是：

> 每秒大约能搬 3000 GB 数据。

所以 HBM3 的“送货能力”比 DDR5 强很多。

你可以把它想成高速公路：

```text
计算单元 = 工厂
内存     = 仓库
内存带宽 = 仓库到工厂之间的道路有多宽
```

路越宽：

```text
每秒能送的数据越多
```

这就是为什么 GPU 做大模型时特别在乎 HBM 带宽。

比如 Decode 阶段，经常不是算力不够，而是：

> Tensor Core 已经等着算了，但 Weight / KV Cache 还没从 HBM 搬过来。

这时就叫：

$$
\text{Memory Bound}
$$

所以一句话记住：

$$
\text{内存带宽 = 单位时间内最多能搬多少数据}
$$
